STAR NET - Website Profil

1. Buat repository GitHub BARU bernama star-net-profile. Jangan gunakan repository aplikasi STAR NET yang sudah berjalan.
2. Upload index.html dan style.css ke root repository.
3. Di Vercel pilih Add New Project lalu import repository star-net-profile.
4. Framework Preset: Other. Kosongkan Build Command dan Output Directory.
5. Klik Deploy.
